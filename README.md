# ✨ My fav - 推し活ポータル Webアプリ

推しのSNS（YouTube, X, Instagram, TikTok）をまとめてチェックでき、推し画像ギャラリーや推し活日数のカウントダウン、活動記録メモを備えた専用ウェブアプリです。

---

## 🚀 すぐに使う方法（ローカルPCで起動）

1. 本フォルダにある **`start.bat`** をダブルクリックします。
2. 自動的にローカルサーバーが起動し、ブラウザでアプリが開きます！
   - URL: `http://localhost:3000/`
   - ※ Node.js などのインストールは一切不要です。Windows標準機能だけで快適に動作します。

---

## 🌟 主な機能

### 1. 複数の推しを登録＆ワンクリック切り替え
- 画面上部のピルボタンで推しをスムーズに切り替えられます。
- 推しごとに**イメージカラー（テーマカラー）**を設定でき、画面全体のアクセントカラーやグラデーションが推し色に変化します。

### 2. アイコン写真のサイズ・形状・ズームカスタマイズ ✨
- ヘッダーのアイコン写真横のきらきらボタン（または「写真・設定」）から以下をいつでも調整可能：
  - **表示サイズ**: コンパクト(小) / 標準(中) / 大きめ(大) / 特大ビッグサイズ
  - **フレーム形状**: まん丸 / ふんわり角丸 / もこもこお花枠 / きらきらハート枠
  - **きらきら発光リング（Glow）**: ON / OFF
  - **写真登録時のズーム・位置スライダー**: スライダーで好みの画角に拡大・位置調整して切り抜き可能

### 3. SNS・複数チャンネル対応（ワンクリックジャンプ）🌸
- **YouTubeの複数チャンネルに対応**:
  - 「メインチャンネル」「サブチャンネル」「ゲーム実況ch」「歌ってみたch」など、複数のチャンネルを自由な名前で何個でも登録可能！
  - それぞれのチャンネルへ**ワンクリックで直接ジャンプ**できます。
- **X (旧Twitter)、Instagram、TikTokも複数アカウント対応**:
  - 公式アカウント、個人垢、サブ垢、スタッフ垢などを自由に登録可能。
- デザインは推し色に馴染む「ふんわりパステル調」で統一。

### 4. 推し活日数カウントダウン
- **推し始めてからの日数**: 「推して 〇〇日目」「〇年〇ヶ月〇日」などを自動計算。
- **次のキリ番記念日**: 100日、200日、500日、1000日記念日までの残り日数と日付を表示。
- **誕生日カウントダウン**: 誕生日までの日数を表示（当日はお祝い演出！）。

### 5. 推し画像ギャラリー＆自動軽量化
- 写真の保存・一覧・拡大表示・ダウンロード（保存）が可能。
- アップロード時にブラウザ側で**自動リサイズ＆WebP圧縮**を実行。スマホで撮影した重い写真（10MB等）も画質を維持したまま150〜300KB程度に軽量化されるため、容量を節約できます。

### 6. 推し活メモ・活動記録
- ライブ参戦記録、CD・グッズ発売日、出演情報、日常の尊い感情をカテゴリ別に記録。

## 📱 スマホとPCのデータ同期（合言葉方式）

「設定」タブから、合言葉を使ってPCとスマホのデータを同期できます。

### 手順：
1. **Supabaseのアカウント作成（完全無料）**:
   - [supabase.com](https://supabase.com/) にアクセスし、無料アカウントを作成。
   - 新規プロジェクト（例: `my-fav`）を作成。
2. **テーブルの作成**:
   - Supabaseの左メニュー「SQL Editor」を開き、以下のSQLを貼り付けて「Run」を実行します：
   ```sql
   CREATE TABLE IF NOT EXISTS my_fav_sync (
     id TEXT PRIMARY KEY,
     data JSONB NOT NULL,
     updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );
   ALTER TABLE my_fav_sync ENABLE ROW LEVEL SECURITY;
   CREATE POLICY "Public sync access" ON my_fav_sync FOR ALL USING (true) WITH CHECK (true);
   ```
3. **キーをアプリに設定**:
   - Supabaseの「Project Settings」→「API」から「Project URL」と「anon public」キーをコピー。
   - アプリの「設定」タブの「Supabase接続情報」に貼り付けて保存。
4. **合言葉を決める**:
   - 「設定」タブで好きな合言葉（例: `my-secret-key-2026`）を入力して保存。
5. **クラウド保存＆スマホで同期**:
   - PCで「クラウドに保存」をクリック。
   - スマホでこのアプリを開き、同じ合言葉を入力して「クラウドから取得」を押すと、すべてのデータが瞬時に同期されます！
